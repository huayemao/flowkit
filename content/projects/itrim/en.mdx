# Product Description
**itrim (i-trim)** is a lightweight, web-based image processing tool built to simplify redundant border removal from images, accessible directly (no download/installation required) across computers and mobile devices.

## Core Capabilities
itrim features intelligent automatic border recognition and trimming, capable of detecting and removing black bars, white edges, —solving the common issue of aspect ratio-caused black bars in movie/TV screenshots. It supports single and batch processing: drag-and-drop/paste images (multi-selection allowed), with all operations completed locally on the client side for ultra-fast speeds, no lags or delays. Post-processing, users can download individual images or use the "Download All" button for one-click batch export.

#### 1. What is it
itrim (also named i-trim) is a lightweight, user-friendly web-based image processing tool designed to solve the pain point of redundant borders (such as black bars, white edges, or any colors) in images. It realizes automatic and batch border trimming without complex operations, making it an efficient alternative to heavy-duty image editing software like Photoshop.

#### 2. How to Use
1. Open the application page directly (no download or installation required, compatible with computers, mobile phones and other devices).
2. Add images to be processed by dragging and dropping or pasting (supports single upload or batch upload via multi-selection drag-and-drop).
3. After the tool automatically identifies and trims the borders, download individual processed images or click the "Download All" button to export all images with one click.
