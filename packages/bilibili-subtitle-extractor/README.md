# B站字幕提取器

一个简单易用的B站视频字幕提取工具，支持提取视频字幕并导出为多种格式。

## 功能特性

- 🎯 支持所有B站视频链接格式
- 📝 自动识别并提取可用的字幕（CC字幕、AI字幕）
- 💾 支持下载SRT和纯文本两种格式
- 🎨 现代化的用户界面
- 📱 响应式设计，支持移动端
- ⚡ 快速提取，实时预览

## 使用方法

1. 在输入框中粘贴B站视频链接
2. 点击"提取字幕"按钮
3. 等待提取完成，预览字幕内容
4. 选择需要的格式进行下载

## 支持的字幕格式

- **SRT格式**: 包含时间轴信息，可用于视频编辑软件
- **纯文本格式**: 适合阅读和翻译使用

## 技术实现

本工具基于以下技术栈：

- React 18 + TypeScript
- Vite 构建工具
- Tailwind CSS
- Shadcn UI 组件库
- B站开放API

## 开发

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建
pnpm build

# 预览
pnpm preview
```

## 注意事项

- 仅支持提取公开视频的字幕
- 部分视频可能没有可用的字幕
- 请遵守B站的使用条款和版权规定
- 提取的字幕仅供个人学习使用

## API说明

本工具使用B站的公开API接口：

- 视频信息获取: `https://api.bilibili.com/x/web-interface/view`
- 字幕列表获取: `https://api.bilibili.com/x/player/v2`
